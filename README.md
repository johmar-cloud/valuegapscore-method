# Value gap score methodology

Interactive methodology page for the Flow Value Investing value gap score. A single static file, `index.html`, with no build step.

Covers the value gap, the VG_Score builder, five worked names from the 12 October 2026 scan, the Z-score, the justified-premium test and a glossary.

Deploy on Vercel or any static host by pointing it at the repository root.

Research and education only, not investment advice.
